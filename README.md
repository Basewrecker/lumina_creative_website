# Lumina Creative ✨

**Lumina Creative** is a modern, visually striking digital agency website built with **HTML**, **CSS**, and **JavaScript**. It showcases elegant UI design, responsive layouts, and smooth transitions to highlight creative agency services and portfolios.

---

## 🚀 Live Demo  
👉 [View Website](https://lumina-creative-kappa.vercel.app/index.html)

---

## 🧩 Features
- Clean, modern design inspired by creative portfolio sites  
- Smooth scrolling and section transitions  
- Modular structure for easy updates  
- Contact and About sections for client engagement  
- Optimized for desktop and tablet viewports  

---

## ⚙️ Tech Stack
- **HTML5** – Semantic structure  
- **CSS3** – Responsive layout and animations  
- **JavaScript (Vanilla)** – Interactive UI behavior  
- **Vercel** – Deployment and hosting  

---

## 🧠 Learning Goals
This project demonstrates:
- Building agency-style layouts from scratch  
- Structuring reusable HTML/CSS components  
- Practicing animation and design consistency  
- Managing a front-end deployment with Vercel
